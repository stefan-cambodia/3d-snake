# 3D Snake 1.8.0 — screenshots

Captured on 2026-11-11 from version 1.8.0 (a ninth sanctuary, Violet Aurora, on its own island; a
fourteenth skin, Nebula Naga; trees in each sanctuary's colours; Malay and Filipino). 1920×1080,
high quality setting, Android emulator (OpenGL renderer), with the autopilot playing the run in
Showcase mode. Free to use for documentation, store pages and presentations. `overview.jpg` is a
captioned contact sheet of all 22. Images 14 to 17 show Amber Autumn and Silver Frost again with
their new leaf colours; compare with [v1.7](../v1.7/README.md) and [v1.5](../v1.5/README.md).
