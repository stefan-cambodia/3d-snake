# 3D Snake 1.1.0 — screenshots

Captured on 2026-11-08 from version 1.1.0 (the relief update: hills, walled terraces and paved
ramps; the game's new name, 3D Snake). 1920×1080, high quality setting, Android emulator (OpenGL
renderer), with the autopilot playing the runs in the Showcase build. Free to use for
documentation, store pages and presentations. `overview.jpg` is a captioned contact sheet of all
of them.
