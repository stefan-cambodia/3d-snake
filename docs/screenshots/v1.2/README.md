# 3D Snake 1.2.0 — screenshots

Captured on 2026-11-10 from version 1.2.0 (each sanctuary has its own island: Golden Dawn keeps the
1.1.0 island, Moonlit Shrine and Misty Morning have new ones). 1920×1080, high quality setting,
Android emulator (OpenGL renderer), with the autopilot playing the runs in the Showcase build. Free
to use for documentation, store pages and presentations. `overview.jpg` is a captioned contact
sheet of all of them.
