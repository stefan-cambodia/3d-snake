# 3D Snake 1.7.0 — screenshots

Captured on 2026-11-11 from version 1.7.0 (an eighth sanctuary, Amber Autumn, on its own island;
a thirteenth skin, Tiger Python; Hindi). 1920×1080, high quality setting, Android emulator (OpenGL
renderer), with the autopilot playing the run in Showcase mode. Free to use for documentation,
store pages and presentations. `overview.jpg` is a captioned contact sheet of all 19. The seven
older islands are unchanged: see [v1.6](../v1.6/README.md), [v1.5](../v1.5/README.md),
[v1.4](../v1.4/README.md), [v1.3](../v1.3/README.md) and [v1.2](../v1.2/README.md).
