# 3D Snake 2.0.0 — screenshots

Captured on 2026-11-11 from version 2.0.0, the environment overhaul: each of the nine sanctuaries
has its own monument, landmarks, shore buildings, columns, stone, plants and weather. 1920×1080,
high quality setting, Android emulator (OpenGL renderer), most of them with the `--tour` camera
(menus hidden). Free to use for documentation, store pages and presentations. `overview.jpg` is a
captioned contact sheet of all 21. Compare with the same islands in [v1.8](../v1.8/README.md) and
earlier, where they shared one gate, one statue and one kind of column.
